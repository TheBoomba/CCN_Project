# CCN_Project

The TCP connections go as follows:
Player <-> Server <-> Player
Within these connection, Players can either communicate a message specifically
to the server or to the other player (asked through a prompt)

To test the current connections, open up in order, in seperate terminals: 
server.py -> player.py -> player.py
After that you can send a message from the players. Once a message is typed, that player
is then asked to ssend to server or player (S or P).
